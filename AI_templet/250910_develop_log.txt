오늘의 개발 내역 (250910):

*   **토스트 메시지 제거**
    *   `CurrentSessionScreen.kt`: 폴드, 체크, 콜, 베팅, 레이즈 등 베팅 액션 버튼 클릭 시 나타나던 토스트 메시지 코드 및 관련 `Toast` import 구문 삭제.

*   **진행중인 세션 이어하기 기능 구현 (기획서 ID 2-1)**
    *   `ActiveSession.kt`: 진행중인 게임 상태(GameState)를 JSON으로 저장하기 위한 Room 엔티티 추가.
    *   `AppDatabase.kt`: `ActiveSession` 엔티티를 포함하도록 데이터베이스 버전 2로 업데이트, 마이그레이션 로직 추가.
    *   `PlayerProfileDao.kt`: `ActiveSession`을 저장, 조회, 삭제하는 DAO 함수 추가.
    *   `build.gradle.kts`: `GameState` 직렬화를 위해 `kotlinx.serialization` 플러그인 및 라이브러리 추가.
    *   `SessionViewModel.kt`: 게임 상태 변경 시(`handleAction`, `newHand` 등) 자동으로 데이터베이스에 세션을 저장하고, 세션 종료 시 삭제하는 로직 구현. `hasActiveSession` StateFlow를 추가하여 UI에 세션 존재 여부 제공.
    *   `AppNavigation.kt`: `HomeScreen`에 `SessionViewModel`을 전달하도록 수정.
    *   `HomeScreen.kt`: `hasActiveSession`을 구독하여 '진행중인 세션' 버튼을 활성화하고, 클릭 시 `loadActiveSession`을 호출하여 게임을 불러오도록 구현.

*   **기존 게임 설정 불러오기 기능 구현 (기획서 ID 1-1)**
    *   `SettingsRepository.kt`: 마지막 게임의 좌석 수와 플레이어 배치를 DataStore에 저장하고 불러오는 `lastSessionSetupFlow` 및 `updateLastSessionSetup` 함수 추가.
    *   `SessionViewModel.kt`: 게임 시작 시 현재 설정을 저장하고, `loadPreviousSetupAndStart` 함수를 통해 기존 설정을 불러와 즉시 게임을 시작하는 로직 구현. `hasPreviousSetup` StateFlow 추가.
    *   `AppNavigation.kt`: `NewSessionScreen`에 `SessionViewModel`을 전달하도록 수정.
    *   `NewSessionScreen.kt`: `hasPreviousSetup`을 구독하여 '기존 게임 설정 불러오기' 버튼을 활성화하고, 클릭 시 `loadPreviousSetupAndStart`를 호출하도록 구현.

*   **버그 수정 및 안정성 강화**
    *   **KSP 빌드 오류 해결**: Room 데이터베이스 마이그레이션 과정에서 발생한 `PROCESSING_ERROR` 해결. `autoMigrations` 대신 `active_session` 테이블을 직접 생성하는 수동 마이그레이션 코드를 `DatabaseModule.kt`에 추가하여 문제 해결.
    *   **`ClassCastException` 해결**: `SettingsRepository`에서 DataStore에 저장된 좌석 수 데이터의 타입이 일치하지 않아 발생하는 앱 강제 종료 현상 수정. `try-catch` 블록을 추가하여, 타입이 다른 데이터가 있더라도 앱이 종료되지 않고 안전하게 처리하도록 로직 강화.
    *   **스레드 충돌 오류 수정**: `SessionViewModel`의 `loadPreviousSetupAndStart` 함수에서 백그라운드 스레드가 UI 상태를 직접 수정하여 발생할 수 있는 잠재적 충돌 문제 해결. 데이터 조회는 백그라운드에서, UI 상태 업데이트는 메인 스레드에서 하도록 코드 구조 변경.
    *   **반복적인 문법 오류 수정**: `replace` 도구 사용 중 발생한 다수의 파일 손상 및 문법 오류를 `write_file`을 통해 전체 파일을 올바른 코드로 덮어쓰는 방식으로 해결.
