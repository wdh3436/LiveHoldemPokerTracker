오늘의 개발 내역 (250916):

*   **게임 중 플레이어 참여/이탈 기능 구현:**
    *   핸드 사이에 플레이어가 나가거나 빈 자리에 새로 참여할 수 있는 기능 추가.
    *   `SessionViewModel`: 핸드 진행 상태(`isHandInProgress`)를 추가하여 플레이어 변경이 가능한 시점을 제어. `addPlayer`, `removePlayer` 함수 구현.
    *   `CurrentSessionScreen`: 빈 좌석(`EmptySeat`)과 플레이어가 있는 좌석(`PlayerSeat`)을 구분하여 표시. 핸드 종료 후 좌석 클릭으로 플레이어 추가/제거 UI(팝업)와 상호작용 하도록 구현.

*   **빈 좌석이 있는 상태로 세션 시작 기능 구현:**
    *   `NewSessionSetupScreen`: 설정한 좌석 수보다 적은 인원으로 게임을 시작할 수 있도록 수정.
    *   '세션 시작' 버튼 활성화 조건을 '2명 이상의 플레이어 할당 시'로 변경.
    *   플레이어 선택창에 '좌석 비우기' 옵션을 추가하여, 설정 단계에서 좌석을 비울 수 있도록 개선.

*   **버그 수정:**
    *   **순서 오류 수정:** 빈 좌석이 있을 때 다음 플레이어 순서가 건너뛰는 문제 해결.
        *   원인: 플레이어 순환 로직이 전체 좌석 수가 아닌 실제 플레이어 수 기준으로 계산됨.
        *   해결: `SessionViewModel`의 순환 로직(`newHand`, `startGame` 등)을 전체 좌석 기준으로 동작하도록 전면 리팩토링. 2인 게임 규칙도 정확하게 수정.
    *   **딜러 버튼 정지 오류 수정:** 다음 핸드로 넘어가도 딜러 버튼이 움직이지 않는 문제 해결.
        *   원인: 핸드 시작 로직 분리로 인한 상태 업데이트 오류.
        *   해결: 핸드 시작 관련 로직을 `setupNewHand` 단일 함수로 통합하여 데이터 정합성 보장.
    *   **컴파일 오류 수정:** 리팩토링 과정에서 발생한 변수명 오타 (`dealerIndex` -> `dealerKey`) 수정.
