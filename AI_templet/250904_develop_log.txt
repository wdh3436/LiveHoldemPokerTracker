    *   `PlayerProfileDao.kt`: 두 프로필의 통계를 합산하고 원본을 삭제하는 `mergeProfiles` 트랜잭션 함수 추가.

*   **앱 설정 기능 구현: 테이블 색상 변경 (기획서 ID 4-1)**
    *   `app/build.gradle.kts`: Jetpack DataStore 의존성 추가.
    *   `SettingsRepository.kt`: DataStore를 사용하여 사용자가 선택한 테이블 색상을 영구적으로 저장하는 저장소 클래스 신규 생성.
    *   `SettingsViewModel.kt`: 설정 화면의 UI와 데이터 로직을 연결하는 ViewModel 신규 생성.
    *   `DatabaseModule.kt`: `SettingsRepository`의 의존성을 Hilt에 제공하도록 수정.
    *   `AppSettingsScreen.kt`: 사용자가 테이블 색상을 선택할 수 있는 UI 구현.
    *   `SessionViewModel.kt`: `SettingsRepository`의 데이터를 구독하여 세션에 적용하도록 수정.
    *   `CurrentSessionScreen.kt`: 저장된 테이블 색상 설정을 실제 세션 화면 배경에 적용.

*   **코드 리팩토링 및 버그 수정**
    *   `NewSessionSetupScreen.kt`: 전역 설정과 중복되는 임시 테이블 색상 선택 UI 및 관련 로직 제거.
    *   Hilt KSP(Kotlin Symbol Processing) 오류, 미선언(Unresolved reference) 오류 등 빌드 과정에서 발생한 다수의 오류 수정.
